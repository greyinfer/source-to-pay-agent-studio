Procurement GenAI prototype

Procurement,run by sevenAI agents.

This is a working prototype of an AI agent team for procurement. Ora, the orchestrator agent, leads six specialist agents through the full source-to-pay cycle, from analysing spend to monitoring suppliers. Each agent recommends; a buyer approves; the value is shown.

How it works, end to end

One example runs through every stage: Harbour Logistics, a fictional company, and its courier spend. Each agent receives something, does one job, and hands its result to the next. A buyer approves before every handoff.

Then the cycle repeats. What Tally and Beacon find each month feeds next quarter's spend analysis, so Sift starts again with better data.

    How value is measured

    The agents use the four value types procurement teams already report on.

    Hard saving

    A lower price than the baseline the company paid before.

    Counted when approved

    Cost avoidance

    A price increase or cost that was prevented, such as a capped renewal.

    Counted when approved

    Cash recovered

    Money returned for overbilling, duplicates or service credits.

    Counted when approved

    Value at risk

    Money that could be lost if nobody acts, such as an unchecked renewal.

    Tracked, never counted

    The basis for each agent's value

    Counting rules

    • Each opportunity is counted once, at the stage where it becomes certain. Early estimates are shown but not added.
    • Value at risk is tracked so it gets action, but never added to the total.
    • Nothing counts until a buyer approves it.
    • AI run cost is shown beside value, so value is judged net of what the AI costs to run.

    Why it matters

    Each agent targets a known pain point in procurement and is judged on a measure procurement teams already track.

    What it would take to run for real

    • Connections to the company's procurement and finance systems
    • Security, access controls and data privacy review
    • Accuracy testing on historic data before go-live
    • Approval workflows that match the company's delegated authority
    • Monitoring of accuracy, adoption and AI run cost after launch
